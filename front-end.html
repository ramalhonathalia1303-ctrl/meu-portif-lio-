Formação técnica

Front-End

Exemplo de página técnica para explicar as tecnologias estudadas e registrar evidências de prática.

HTML

HTML é uma linguagem utilizada para criar e estruturar páginas de sites na internet. Com ela, podemos adicionar títulos, textos, imagens, vídeos, links e botões, organizando tudo o que aparece em uma página. Durante os estudos, podemos aprender como o HTML funciona e como utilizá-lo para desenvolver sites, colocando em prática nossos conhecimentos de tecnologia e programação.

<h1>Meu projeto</h1>

CSS

CSS é uma linguagem utilizada para definir a aparência e o estilo de um site. Com ela, podemos escolher cores, fontes, tamanhos de textos, imagens, fundos e organizar os elementos na página. Enquanto o HTML cria a estrutura do site, o CSS deixa tudo mais bonito e organizado. Durante os estudos, aprendemos como utilizar essa linguagem para personalizar páginas e desenvolver sites com diferentes estilos e designs.

.card { padding: 16px; }

JavaScript

JavaScript (JS) é uma linguagem de programação utilizada para adicionar interatividade e funcionalidades aos sites. Por meio dela, podemos criar botões que realizam ações, animações, menus, cálculos e outras funções. No Visual Studio Code (VS Code), podemos escrever e testar códigos em JavaScript, colocando em prática nossos conhecimentos de programação. Enquanto o HTML estrutura o site e o CSS define sua aparência, o JavaScript faz com que ele tenha mais funcionalidades e interaja com o usuário.

botao.addEventListener("click", ...);

Meu exercício

Ao desenvolver o site sobre Casa Inteligente, aprendi na prática como funciona o desenvolvimento Front-End, utilizando HTML para estruturar as páginas, CSS para personalizar o visual, escolhendo cores, fontes e posicionamento dos elementos, e JavaScript para adicionar funcionalidades e interatividade. Também aprendi a utilizar o Visual Studio Code para escrever e organizar os códigos. Essa experiência me permitiu colocar em prática os conhecimentos adquiridos e entender melhor como funciona a criação de um site, desde sua estrutura até sua aparência.
