PORTFÓLIO DO ESTUDANTE — HTML, CSS E JAVASCRIPT
=================================================

ABRIR O PROJETO
1. Extraia o arquivo ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra index.html no navegador.
4. Para editar, altere os arquivos .html, css/estilo.css e js/site.js.

MODELOS INCLUÍDOS
- index.html: página inicial com menu horizontal, carrossel horizontal e carrossel vertical.
- paginas/areas-do-saber.html: cards de áreas do conhecimento.
- paginas/ciencias-natureza.html, ciencias-humanas.html, linguagens.html e matematica.html.
- paginas/disciplina-*.html: modelos individuais para disciplinas.
- paginas/formacao-tecnica.html e paginas/front-end.html.
- paginas/curriculo.html, memorias.html, projeto-destaque.html, jornada.html e contato.html.

CARROSSEIS
- Horizontal: CSS usa display:flex, overflow-x:auto e scroll-snap-type:x mandatory.
- Vertical: CSS usa overflow-y:auto e scroll-snap-type:y mandatory.
- js/site.js associa os botões de seta às funções scrollBy().
- O menu horizontal superior usa Flexbox e vira menu compacto em telas estreitas.

IMAGENS
- As imagens em imagens/ são ilustrações fictícias e recortes de uma imagem conceitual gerada para servir de exemplo visual. Não representam pessoas reais conhecidas.
- Substitua os arquivos pelas fotos do estudante e imagens autorizadas.
- Mantenha o mesmo nome do arquivo ou atualize o atributo src no HTML.
- Não publique imagens de colegas sem autorização.

ESTRUTURA DE PASTAS
portfolio/
  index.html
  css/estilo.css
  js/site.js
  imagens/
  paginas/

COMO ADICIONAR UMA PÁGINA
1. Duplique uma página existente em paginas/.
2. Renomeie o arquivo, por exemplo projeto-novo.html.
3. Mantenha o link para ../css/estilo.css e ../js/site.js.
4. Atualize o título, o conteúdo e os links do menu.
5. Teste os links e imagens no navegador.

COMO TROCAR O NOME E A FOTO
- Abra index.html e altere “João Silva” para o nome desejado.
- Troque imagens/estudante.jpg por uma foto autorizada, mantendo o nome ou atualizando src.
- Atualize também a identificação na página paginas/curriculo.html.

OBSERVAÇÃO
O formulário de contato é apenas demonstrativo e não envia mensagens para um servidor.
